# 3.0 Tutorial Narrative 2.0 (自由贸易导向版)

## 3.0.1 设计哲学
本版教程旨在解决玩家反馈的“强行推着走”的问题。通过将指令从“命令式”转变为“建议式”，并放宽任务完成的判定条件，让玩家在引导中感受到更多的自主权，同时依然能掌握核心的“套利”机制。

## 3.0.2 核心改进点
1.  **减少强迫感**：将原来的“必须买木头”改为“建议买木头”，完成条件改为“只要进行了任何买入操作”。
2.  **任务合并**：将“选择货物”、“调整滑块”、“平衡报价”、“确认交易”这四个繁琐的步骤合并为一个大任务。不再每一步都弹框中断玩家。
3.  **宽松的数值限制**：取消对买入数量的严格限制，只要玩家买了东西就算过关。
4.  **自由的卖出逻辑**：卖出阶段不再锁死特定货物，而是引导玩家观察获利概念。
