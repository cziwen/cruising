# 2.17 通知系统 (Notification System)

## 2.17.1 概述
通知系统用于向玩家展示即时的游戏反馈（如到港提醒、战斗开始、工资结算等）。提示显示在屏幕右上角，支持多重平滑叠加。

## 2.17.2 核心特性
- **叠加显示**：支持最多同时显示 3 个提示条目。
- **自动管理**：当出现第 4 个提示时，最旧的提示将自动执行折叠消失动画，其余提示平滑向上平移。
- **交互反馈**：点击提示将开启 3 秒倒计时，倒计时结束后提示自动消失。
- **纸质风格**：使用特定的纸质 UI 素材及 23 帧的序列帧折叠消失动画。

## 2.17.3 调用接口
系统通过 `NotificationSystem` 单例提供全局访问接口：
```dart
NotificationSystem.instance.showNotification("提示消息内容");
```

## 2.17.4 触发场景
- **到港提醒**：当船只成功抵达目的地港口时触发。
- **战斗提醒**：当触发海上战斗遭遇敌船时触发。
- **工资结算**：每日 00:00 结算工资时，提示支付成功或金币不足导致欠薪的信息。
