# 3.0 Tutorial Narrative 3.0 (保姆级引导版)

## 3.0.1 设计哲学
3.0 版本教程回归了更为精细的“保姆级”引导。相比 2.0 版本的自由导向，3.0 版本通过拆分步骤（如将“进入市场”与“选中货物”分开）和强制高亮，确保即便是第一次接触此类游戏的玩家也能完全理解每一个交互环节的功能。

## 3.0.2 核心改进点
1.  **步骤细化**：不再合并复杂的交互，而是将“打开列表”、“选择港口”、“打开市场”、“选中商品”、“确认交易”每一个环节都作为一个独立的任务 ID，确保玩家不会在复杂的 UI 中迷失。
2.  **强制性增强**：所有关键步骤均设为 `is_mandatory: true`，屏蔽了非引导区域的干扰。
3.  **明确的目标感**：通过 `T04c_select_wood` 等具体指令，让玩家明确感知到“选中货物”这个动作在交易流中的必要性。
4.  **剧情连贯性**：强化了“灯塔岛买木材 -> 贸易港卖木材”的经典贸易模型，作为玩家理解“物价差”的第一课。
