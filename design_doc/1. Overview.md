# 1. Overview

## 1.1 Elevator Pitch  
在一个 2D 侧视的单场景中，你扮演一名船长，通过贸易赚取金币，升级船只，以追求更多的财富。游戏采用简化的经营玩法，船永远保持在屏幕中央，通过背景切换来表现不同的港口场景。

## 1.2 核心玩法（Core Gameplay）  
玩家的主要活动围绕以下四大板块展开：  
- **贸易与买卖**：在各大港口低价采购商品，高价售出获利。  
- **船只升级**：使用金币强化船体、提升载货量或装备武器。  
- **主岛建设**：经营私人领地，通过升级获取被动税收、扩展仓库并见证岛屿外观进化。
- **港口探索**：访问不同港口，发现新的贸易机会与招募更优秀的船员。

## 1.3 核心循环（Core Loop）  
1. 在港口界面，查看当前港口的商品价格
2. 购买低价商品，自动装载到船上
3. 选择下一个目的地港口（或选择"海上"进入海上状态，或返回主岛存取物资/领取税收）
4. 背景切换，表示"航行"到新场景（选择"海上"时立即进入海上状态，可随时选择新目的地）
5. 在新港口出售商品，赚取差价
6. 投资：花费金币进行船只升级或**主岛建设**（提升税收与仓库能力）
7. 解锁更多港口与岛屿视觉阶段，重复循环

## 1.4 游戏架构

### 1.4.1 单场景与跨平台架构
- **单场景设计**：游戏所有操作在同一画面完成，船只固定，背景切换表现航行。
- **跨平台抽象架构**：为了支持在 Windows 原生环境（使用 FFI/Win32 API 实现壁纸模式）和 Web/Mac 环境下同时开发与运行，系统采用了 **条件导出 (Conditional Exports)** 机制。
  - 核心系统（如 `WindowController`, `TrayController`, `FileLogger`）定义统一接口。
  - 通过 `export ... if (dart.library.io) ...` 在构建时自动切换 Stub 实现或原生实现，确保 Web 平台编译器不解析不支持的原生库。

### 1.4.2 全局比例与10层渲染系统
- **全局比例锁定**：整个应用程序（MaterialApp）由 `ScaleWrapper` 包裹，强制锁定 16:9 的纵横比。在非 16:9 的屏幕（如网页全屏或长屏手机）上，会自动在两侧或上下填充黑色背景（Black Bars），确保游戏内容不拉伸且布局一致。
- **渲染层级**：游戏画面由10个层级组成（从底到顶）：
  - **背景层（Layer 0）**：海洋底色渐变、天空渐变及海底背景。
  - **天体层（Layer 0.5）**：太阳/月亮等天体元素（位于海底背景之上，云浪之下）。
  - **背景装饰层（Layer 0.8）**：多层视差滚动的背景海浪与云朵。
  - **近背景层（Layer 1）**：近距离背景（港口建筑、岛屿、海岸线等，随目的地切换）。
  - **船层（Layer 2）**：玩家船只，永远居中显示，包含呼吸动画。
  - **前景波浪层（Layer 2.3）**：位于船只前方的动态波浪，增强层次感。
  - **屏幕效果层（Layer 2.5）**：全屏视觉效果（如全屏渐变黑屏、转场效果）。
  - **UI层（Layer 3）**：主要交互界面（状态栏、对话框、交易界面等）。
  - **时间显示（Layer 3.5）**：左上角时间显示（独立层，确保不被部分 UI 遮挡）。
  - **通知覆盖层（Layer 4）**：实时的系统通知与反馈。
  - **任务引导层（Layer 5）**：最顶层的任务提示、高亮指引与交互屏蔽。

## 1.5 视觉风格
- **美术风格**：像素艺术 (Pixel Art)，采用 2D 侧视视角。
- **字体系统**：全游戏统一使用 `ArkPixel` (方舟像素字体) 10px 变体。通过注册多语言子集 (ZH, EN, JA, KO)，实现在不同语言环境下的完美像素对齐与风格统一。
- **色彩规范**：基于纸质 UI 的深褐色墨水风，配合环境色的动态渐变。

## 1.6 系统概述
- **贸易系统**：基于交换的交易机制，动态价格系统，增量价格计算，自动装载。
- **导航系统**：基于距离（节）的航行计算，航速计算，进度显示，dt增量更新，支持"海上"特殊地点（让玩家离开港口进入海上状态）。
- **场景系统**：10层渲染系统，多层视差背景切换，港口切换动画，天体轨迹计算，屏幕效果层。
- **船只系统**：简化的船只数据模型，支持升级和属性管理，载货量基于重量系统。
- **船员系统**：船员管理，职业分配，加成计算，工资结算，技能值曲线生成。
- **UI系统**：状态栏显示，对话框系统，按钮布局，时间显示，响应式设计。
- **昼夜系统**：时间管理，昼夜循环，季节系统，dt增量更新，动态分层视觉滤镜与天空渐变。
- **音频系统**：基于配置驱动的 BGM/SFX 管理，支持音频交叉淡入淡出、随机环境音叠加。
- **无边框模式**：Windows 平台原生沉浸式模式，支持系统托盘控制、平滑切换机制。
- **通知系统**：实时通知系统（Notification Overlay），支持教程提示与信息反馈。
- **战斗系统**：战斗触发，战斗逻辑，战斗结果处理，统一游戏时钟。
- **存档系统**：多槽位管理（自动存档+3个手动存档），自动存档，JSON序列化，跨平台存储。
- **调试系统**：调试面板，时间倍数调整，跳过航行动画，开发工具。
- **港口系统**：交互式世界地图选择（支持地图位置配置与 hover 反馈），港口列表管理，距离计算，支持"海上"特殊地点显示。
- **天气系统**：天气状况（平静、小风、风暴），航速修正。
- **主岛系统**：独立的玩家岛屿养成玩法，支持税收自动产出、仓库存储、多级视觉进化及经济升级。
- **配置系统**：统一管理货物（`goods.json`）与港口（`ports.json`）的静态数据，支持外部解耦配置。
- **版本管理**：集中式版本常量管理（`version_constants.dart`），遵循语义化版本规则，并实时显示在主菜单界面。
- **任务系统**：通用的任务驱动系统，支持教程引导、剧情驱动、强制交互、UI高亮及复杂的条件达成检查。
