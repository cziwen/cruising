# 3.1 岛屿经济数值设计 (Island Economics Design)

## 3.1.1 核心理念
以“贸易港（Port 2）”作为全游戏的经济平衡基准（Benchmark）。所有的商品属性和港口配置均以贸易港为 1.0 参照系。其他岛屿通过系数偏移来定义其经济特性。

## 3.1.2 基准配置 (Benchmark: Port 2 & Base Config)
这是全游戏的中位数，代表一个发育完全、供需平衡的成熟市场。

| 商品 | 基础价格 (P₀) | 价格敏感度 (α) |
| :--- | :--- | :--- |
| **食物 (Food)** | 12.0 | 0.15 |
| **淡水 (Water)** | 8.0 | 0.10 |
| **朗姆酒 (Rum)** | 20.0 | 0.18 |
| **木材 (Wood)** | 16.0 | 0.12 |
| **金属 (Metal)** | 25.0 | 0.20 |
| **石材 (Stone)** | 18.0 | 0.15 |
| **布料 (Cloth)** | 15.0 | 0.12 |
| **皮革 (Leather)** | 22.0 | 0.16 |

## 3.1.3 变体矩阵 (Variant Matrix)
用于根据港口定位调整经济参数。注意：基准库存 (S₀) 由港口根据其生产/需求定位直接设定，不作为全局商品属性。

| 港口类型 | 描述 | P₀ 系数 | α 系数 | S₀ 设定建议 |
| :--- | :--- | :--- | :--- | :--- |
| **基准 (Benchmark)** | 贸易港标准 | 1.0 | 1.0 | 中等库存 (300-500) |
| **初始主岛 (Home Lv.0)**| 初始劣势状态 | 0.8 | 2.0 | 极低库存 (0-100) |
| **产地 (Origin)** | 盛产某物，适合买入 | 0.6 | 0.8 | 极高库存 (1000-2000) |
| **需求地 (Demand)** | 匮乏某物，适合卖出 | 1.5 | 1.2 | 低库存/零库存 (0-200) |

## 3.1.4 港口具体定位与偏移

### 1. 我的岛屿 (home_island)
- **定位**：待开发的荒地。玩家必须通过后续升级系统来逐步解锁物资种类，并将经济系数调优至甚至超过基准水平。
- **配置**：全商品应用 **[初始主岛]** 变体。
- **物资解锁**：初始仅有基础物资，随总等级提升逐步解锁（详见 2.13.2）。
- **岛屿描述**：一座尚未苏醒的荒芜海岛，补给稀薄，港口设施简陋，等待玩家重新点燃生机。
- **岛屿特点**：
  - 市场极不成熟，物资供应从基础品类开始。
  - 随着养成进度，港口商店会引入建材、金属以及各类奢侈品。
  - 依赖外部航线带回基础物资，推动早期探索动机。
  - 随升级逐步恢复活力，最终可向基准港靠拢甚至超越。

### 2. 起始港 (port_1)
- **定位**：初级资源供应站。
- **木材**：应用 **[产地]** 变体。
- **其他**：应用 **[基准]** 变体。
- **岛屿描述**：港口周围密布林地与简易码头，是新人最先接触的“资源补给站”。
- **岛屿特点**：
  - 木材充足、价格友好，适合买入囤积。
  - 基础物资齐全，交易节奏平稳。
  - 其他商品保持中性水平，便于理解基准市场。

### 3. 贸易港 (port_2)
- **定位**：经济枢纽。
- **全商品**：应用 **[基准]** 变体（与 `base` 配置完全一致）。
- **岛屿描述**：商船云集、市场成熟的中心港，价格与供需最稳定，是全球贸易的参照点。
- **岛屿特点**：
  - 供需均衡，价格波动小，适合作为套利对照。
  - 市场信息集中，玩家可以在此评估各地行情。
  - 货物覆盖面完整，交易体验最“标准”。

### 4. 香料港 (port_3)
- **定位**：异域物资中心。
- **香料**：应用 **[产地]** 变体。
- **食物、金属**：应用 **[需求地]** 变体。
- **木材**：应用 **[基准]** 变体。
- **岛屿描述**：香气弥漫的港湾，异域商队汇聚，货摊以香料与奇珍闻名。
- **岛屿特点**：
  - 香料产量高、价格低，是核心买入地。
  - 食物与金属常年匮乏，形成明显卖出机会。
  - 木材维持基准，便于补给与中转。

### 5. 铁炉岛 (port_4)
- **定位**：重工业中心。
- **金属、石材**：应用 **[产地]** 变体。
- **朗姆酒、丝绸**：应用 **[需求地]** 变体。
- **其他**：应用 **[基准]** 变体。
- **岛屿描述**：烟囱林立、火炉终日不熄的工业岛，矿脉与石场支撑着重工贸易。
- **岛屿特点**：
  - 金属与石材供给极强，是重工业原料主产地。
  - 生活与奢侈品稀缺，朗姆酒、丝绸溢价明显。
  - 其他货品处于基准水平，便于做中转补给。

### 6. 织梦湾 (port_5)
- **定位**：轻工业与纺织中心。
- **布料、丝绸**：应用 **[产地]** 变体。
- **木材、皮革**：应用 **[需求地]** 变体。
- **其他**：应用 **[基准]** 变体。
- **岛屿描述**：纺机声与染坊香交织的海湾，帆布与丝线从这里流向各地。
- **岛屿特点**：
  - 布料与丝绸产出丰盛，是轻工成品集散地。
  - 木材与皮革紧缺，形成稳定的高价卖点。
  - 其余商品保持中位数，交易节奏平衡。

### 7. 翡翠领 (port_6)
- **定位**：大农业供应区。
- **食物、淡水、朗姆酒**：应用 **[产地]** 变体。
- **金属、石材**：应用 **[需求地]** 变体。
- **其他**：应用 **[基准]** 变体。
- **岛屿描述**：田野与水渠铺展的绿色群岛，是远航队伍最可靠的补给腹地。
- **岛屿特点**：
  - 食物、淡水、朗姆酒供应充足，补给效率最高。
  - 金属与石材偏缺，重工材料在此高价回收。
  - 其他货物维持基准，适合作为航线中继点。

### 8. 远古遗址 (port_7)
- **定位**：高价值奢侈品发掘地。
- **象牙、艺术品**：应用 **[产地]** 变体。
- **食物、淡水**：应用 **[需求地]** 变体。
- **其他**：应用 **[基准]** 变体（库存量较低）。
- **岛屿描述**：被风沙与藤蔓覆盖的遗迹群岛，少量高价值遗物在暗市中流通。
- **岛屿特点**：
  - 象牙与艺术品出产稀贵但利润极高。
  - 食物与淡水长期不足，生存补给紧张。
  - 其余货物库存偏低，交易波动更敏感。

## 3.1.5 数值平衡目标
1. **利润空间**：从产地（P₀ * 0.6）到需求地（P₀ * 1.5）存在巨大的毛利空间，足以覆盖买卖价差和运输成本。
2. **升级动力**：主岛初始 2.0 倍的 Alpha 惩罚使得在主岛贸易极其不划算，迫使玩家探索远海并回馈主岛升级。
3. **动态波动**：产地的高 S₀ 保证了即便玩家一次性买入大量货物，价格上升也相对平缓。

## 3.1.6 货物出现逻辑 (Goods Availability Logic)

为了增强岛屿的专业化特性并简化非核心贸易的操作，系统应用了以下出现逻辑：

1. **基础物资 (Basic Goods)**：
   - 包含：食物、淡水、朗姆酒。
   - **强制性**：所有港口（包括主岛初始状态）必须配置基础物资，以确保玩家无论身处何地都能获得生存补给。
2. **物资解锁 (Home Island Only)**：
   - 主岛拥有特殊的物资解锁机制，随着等级（Lv.0 - Lv.7）提升，逐步从基础物资扩展到全品类物资。
3. **工业材料与奢侈品 (Optional Goods)**：
   - 包含：木材、金属、石材、布料、皮革、香料、丝绸、象牙、艺术品。
   - **选配性**：仅在港口作为其“产地”或“需求地”时才会出现在商人的初始货架上。
3. **动态可见性**：
   - 如果某货物未在港口配置（即 $S_0 = 0$），且该港口当前实际库存为 0，则该货物在交易界面隐藏。
   - 若玩家将此类货物卖给该港口（使实际库存 > 0），则该货物会变为可见并允许再次买卖。
