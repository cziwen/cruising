# 3.1 岛屿经济数值设计 (Island Economics Design)

## 3.1.1 核心理念
以“贸易港（Port 2）”作为全游戏的经济平衡基准（Benchmark）。所有的商品属性和港口配置均以贸易港为 1.0 参照系。其他岛屿通过系数偏移来定义其经济特性。

## 3.1.2 基准配置 (Benchmark: Port 2 & Base Config)
这是全游戏的中位数，代表一个发育完全、供需平衡的成熟市场。

| 商品 | 基础价格 (P₀) | 价格敏感度 (α) |
| :--- | :--- | :--- |
| **食物 (Food)** | 12.0 | 0.15 |
| **淡水 (Water)** | 8.0 | 0.10 |
| **朗姆酒 (Rum)** | 20.0 | 0.18 |
| **木材 (Wood)** | 16.0 | 0.12 |
| **金属 (Metal)** | 25.0 | 0.20 |
| **石材 (Stone)** | 18.0 | 0.15 |
| **布料 (Cloth)** | 15.0 | 0.12 |
| **皮革 (Leather)** | 22.0 | 0.16 |
| **香料 (Spice)** | 30.0 | 0.25 |

## 3.1.3 变体矩阵 (Variant Matrix)
用于根据港口定位调整经济参数。注意：基准库存 (S₀) 由港口根据其生产/需求定位直接设定，不作为全局商品属性。

| 港口类型 | 描述 | P₀ 系数 | α 系数 | S₀ 设定建议 |
| :--- | :--- | :--- | :--- | :--- |
| **基准 (Benchmark)** | 贸易港标准 | 1.0 | 1.0 | 中等库存 (300-500) |
| **初始主岛 (Home Lv.0)**| 初始劣势状态 | 0.8 | 2.0 | 极低库存 (0-100) |
| **产地 (Origin)** | 盛产某物，适合买入 | 0.6 | 0.8 | 极高库存 (1000-2000) |
| **需求地 (Demand)** | 匮乏某物，适合卖出 | 1.5 | 1.2 | 低库存/零库存 (0-200) |

## 3.1.4 港口具体定位与偏移

### 1. 我的岛屿 (home_island)
- **定位**：待开发的荒地。玩家必须通过后续升级系统来逐步将系数调优至甚至超过基准水平。
- **配置**：全商品应用 **[初始主岛]** 变体。

### 2. 起始港 (port_1)
- **定位**：初级资源供应站。
- **木材**：应用 **[产地]** 变体。
- **其他**：应用 **[基准]** 变体。

### 3. 贸易港 (port_2)
- **定位**：经济枢纽。
- **全商品**：应用 **[基准]** 变体（与 `base` 配置完全一致）。

### 4. 香料港 (port_3)
- **定位**：异域物资中心。
- **香料**：应用 **[产地]** 变体。
- **食物、金属**：应用 **[需求地]** 变体。
- **木材**：应用 **[基准]** 变体。

### 5. 铁炉岛 (port_4)
- **定位**：重工业中心。
- **金属、石材**：应用 **[产地]** 变体。
- **朗姆酒、丝绸**：应用 **[需求地]** 变体。
- **其他**：应用 **[基准]** 变体。

### 6. 织梦湾 (port_5)
- **定位**：轻工业与纺织中心。
- **布料、丝绸**：应用 **[产地]** 变体。
- **木材、皮革**：应用 **[需求地]** 变体。
- **其他**：应用 **[基准]** 变体。

### 7. 翡翠领 (port_6)
- **定位**：大农业供应区。
- **食物、淡水、朗姆酒**：应用 **[产地]** 变体。
- **金属、石材**：应用 **[需求地]** 变体。
- **其他**：应用 **[基准]** 变体。

### 8. 远古遗址 (port_7)
- **定位**：高价值奢侈品发掘地。
- **象牙、艺术品**：应用 **[产地]** 变体。
- **食物、淡水**：应用 **[需求地]** 变体。
- **其他**：应用 **[基准]** 变体（库存量较低）。

## 3.1.5 数值平衡目标
1. **利润空间**：从产地（P₀ * 0.6）到需求地（P₀ * 1.5）存在巨大的毛利空间，足以覆盖买卖价差和运输成本。
2. **升级动力**：主岛初始 2.0 倍的 Alpha 惩罚使得在主岛贸易极其不划算，迫使玩家探索远海并回馈主岛升级。
3. **动态波动**：产地的高 S₀ 保证了即便玩家一次性买入大量货物，价格上升也相对平缓。

## 3.1.6 货物出现逻辑 (Goods Availability Logic)

为了增强岛屿的专业化特性并简化非核心贸易的操作，系统应用了以下出现逻辑：

1. **基础物资 (Basic Goods)**：
   - 包含：食物、淡水、朗姆酒。
   - **强制性**：所有港口必须配置基础物资，以确保玩家无论身处何地都能获得生存补给。
2. **工业材料与奢侈品 (Optional Goods)**：
   - 包含：木材、金属、石材、布料、皮革、香料、丝绸、象牙、艺术品。
   - **选配性**：仅在港口作为其“产地”或“需求地”时才会出现在商人的初始货架上。
3. **动态可见性**：
   - 如果某货物未在港口配置（即 $S_0 = 0$），且该港口当前实际库存为 0，则该货物在交易界面隐藏。
   - 若玩家将此类货物卖给该港口（使实际库存 > 0），则该货物会变为可见并允许再次买卖。
