# Playtest 反馈汇总

## 1. 视觉与美术风格
- **战斗画面**：目前比较平淡（plain），需要更多的打击感或细节打磨。
- **岛屿资源**：相比清晰的船只，岛屿看起来比较模糊。需要提高岛屿贴图/资源的清晰度。
- **字体风格**：目前的字体与游戏风格不符。建议更换为更契合游戏主题的字体。
- **易读性**：普遍反馈部分文字（字体）看不太清楚。

## 2. UI 与 UX（用户体验）
- **整体 UI**：界面设计还可以，能够接受。
- **交易界面**：交易滑块（slider）不好精确调整数量。需要一种更精准的数值调整方式。
- **UI 溢出**：港口文字和其他 UI 元素在某些地方出现了溢出（overflow）[Done]。
- **时间显示**：建议在时钟上增加 AM/PM 标识。
- **地图系统**：地图不要只是一个列表，而应该是一块真实的图形化地图。鼠标悬停（hover）在地点上时应该有高亮效果。[Done]

## 3. 玩法与叙事
- **新手教程**：教程显得生硬且带有强制性（“强行把玩家往前推”）。需要更平滑、更少干扰。[Done]
- **岛屿数据**：建议给岛屿增加人口数据，以提供更多的背景信息和深度。
- **直观理解**：玩家对市场（贸易）、船厂和船员系统有直观的理解。

## 4. 商业与市场
- **定价**：能够接受 1 元钱的定价。
- **测试背景**：注意测试人员（playtester）可能存在个人偏好/偏见（bias）。
