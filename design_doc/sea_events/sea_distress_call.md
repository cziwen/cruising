# 遇难求救 (Distress Call)

## One-liner
发现一艘即将沉没的救生艇或废弃的小型货船，船长需要决定如何处置。

## Trigger
- **触发窗口**：航行进度 10% - 90%
- **触发概率**：基础 5%
- **冷却时间**：48 游戏小时
- **前提条件**：无

## Choices
1. **全力救援**：耗费物资和时间救起幸存者。
2. **打捞物资**：放弃救援，仅带走能用的资源。
3. **无视并离开**：保持现状，专注于自己的航程。

## Effects
- **选项 1 (救援)**：
  - `time += 2 游戏小时`
  - `water -= 10kg`, `food -= 10kg`
  - `gold += 500` (获救者的谢礼) 或 `crewMorale += 20`
- **选项 2 (打捞)**：
  - `durability -= 5` (碰撞风险)
  - `randomGoods += random(30, 80)kg`
- **选项 3 (离开)**：
  - `crewMorale -= 5` (如果有道德高尚的船员)

## UI
- **呈现方式**：背景出现漂浮的残骸和救生艇。
- **对话框**：`PaperDialog` 展示场景描述和求救信号。
- **反馈**：通过 `NotificationSystem` 播报救援结果或打捞到的具体物资。
