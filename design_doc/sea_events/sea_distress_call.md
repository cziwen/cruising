# 遇难求救 (Distress Call)

## One-liner
发现一艘即将沉没的救生艇或废弃的小型货船，船长需要决定如何处置。

## Trigger
- **触发窗口**：航行进度 10% - 90%
- **触发概率**：基础 7%
- **冷却时间**：48 游戏小时
- **前提条件**：无

## Choices
1. **立即营救**：放下救生艇，接纳幸存者。
2. **打捞残骸**：只收集漂浮的物资，不理会求救。
3. **冷酷拒绝**：保持航向，不要多管闲事。

## Effects
- **选项 1 (营救)**：
  - `timeSkip: 2`（耗费 2 游戏小时）
  - `goldChange: [200, 500]`（获救者的谢礼）
- **选项 2 (打捞)**：
  - `addRandomGoods: [5, 15]`（随机获得 5-15 单位某种货物）
- **选项 3 (拒绝)**：
  - 无任何效果。

## UI
- **呈现方式**：背景出现漂浮的残骸和救生艇。
- **对话框**：`PaperDialog` 展示场景描述和求救信号。
- **反馈**：通过 `NotificationSystem` 播报救援结果或打捞到的具体物资。
