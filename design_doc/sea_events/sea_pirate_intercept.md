# 海盗拦截 (Pirate Intercept)

> **注意**：此事件未作为独立事件实现。战斗选项已合并到「商船邂逅」(`sea_merchant_ship`) 事件的第三个选项 `merchant_raid` 中。以下为原始设计文档，仅供参考。

## One-liner
遭遇海盗快艇拦截，这是关于“钱财”与“性命”的博弈。

## Trigger
- **触发窗口**：航行进度 15% - 85%
- **触发概率**：基础 7%
- **冷却时间**：12 游戏小时
- **前提条件**：`isCombatUnlocked == true`

## Choices
1. **拒绝并交火**：立即进入战斗。
2. **交买路财**：支付一部分金币以避免战斗。
3. **弃货保命**：随机丢弃 20% 的载货，利用减轻负重逃跑。

## Effects
- **选项 1 (战斗)**：
  - 调用 `startCombat()`。
- **选项 2 (交钱)**：
  - `gold -= min(gold * 0.1, 500)`
  - 海盗离去，航行继续。
- **选项 3 (弃货)**：
  - `inventory.removeRandom(0.2)`
  - `travelProgress += 0.02`
  - 成功躲避。

## UI
- **呈现方式**：背景音乐切换至战斗前奏，敌船从右侧快速逼近并保持在侧方。
- **对话框**：`PaperDialog` 弹出海盗的最后通牒文字。
- **反馈**：交钱后播放海盗滑出的动画；选择战斗则直接进入 `CombatSystem` 视觉切换。
