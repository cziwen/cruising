# 顺风/逆风 (Tailwind/Headwind)

## One-liner
遭遇海面风向突变，这将显著改变船只的航行效率。

## Trigger
- **触发窗口**：航行进度 10% - 90%（默认）
- **触发概率**：顺风 12%、逆风 12%（作为两个独立事件分别触发）
- **冷却时间**：8 游戏小时（各自独立冷却）
- **前提条件**：无

## Choices
- **即时通知类事件**，仅有一个确认按钮（顺风："太棒了！"，逆风："真倒霉..."）。

## Effects
- **顺风 (Tailwind)**：
  - `speedMultiplier: 1.5`
  - `durationHours: 12`
- **逆风 (Headwind)**：
  - `speedMultiplier: 0.7`
  - `durationHours: 12`

## UI
- **呈现方式**：背景出现横向的白色风速线条动画。
- **提示**：通过 `NotificationSystem` 提示：“风向转变！目前正处于[顺风/逆风]状态，航速已调整。”
- **反馈**：顶部的剩余航行时间会实时重新计算。
