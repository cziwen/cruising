# 顺风/逆风 (Tailwind/Headwind)

## One-liner
遭遇海面风向突变，这将显著改变船只的航行效率。

## Trigger
- **触发窗口**：航行进度 10% - 90%
- **触发概率**：基础 15% (顺风/逆风各一半)
- **冷却时间**：8 游戏小时
- **前提条件**：无

## Choices
- **即时通知类事件**，无玩家选项。

## Effects
- **如果是顺风 (Tailwind)**：
  - `currentSpeedMultiplier = 1.25`
  - 持续时间：4 游戏小时
- **如果是逆风 (Headwind)**：
  - `currentSpeedMultiplier = 0.75`
  - 持续时间：4 游戏小时

## UI
- **呈现方式**：背景出现横向的白色风速线条动画。
- **提示**：通过 `NotificationSystem` 提示：“风向转变！目前正处于[顺风/逆风]状态，航速已调整。”
- **反馈**：顶部的剩余航行时间会实时重新计算。
