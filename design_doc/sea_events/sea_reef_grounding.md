# 暗礁/搁浅 (Reef Grounding)

## One-liner
由于领航失误或航道复杂，船只触碰暗礁或陷入浅滩，导致航程中断。

## Trigger
- **触发窗口**：航行进度 30% - 70%
- **触发概率**：基础 4%
- **冷却时间**：36 游戏小时
- **前提条件**：水手总技能 < 15

## Choices
1. **强行脱困**：全速开倒车，试图冲出暗礁。
2. **耐心等待涨潮**：原地休整，等待潮水将船抬起。
3. **检查受损并维修**：派船工检查并在原地进行简易维修后再脱困。

## Effects
- **选项 1 (强行)**：
  - `durability -= random(30, 60)`
  - `time += 0.5 游戏小时`
- **选项 2 (等待)**：
  - `time += 4 游戏小时`
  - 无耐久损耗。
- **选项 3 (维修)**：
  - `time += 2 游戏小时`
  - `durability += 10`
  - 随后安全脱困。

## UI
- **呈现方式**：船只产生剧烈震动，背景出现浅色礁石阴影，航行进度条锁定。
- **对话框**：`PaperDialog` 提示：“船底传来剧烈的摩擦声！我们搁浅了。”
- **反馈**：脱困后进度条恢复更新。
