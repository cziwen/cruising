# 2.15 Windows 无边框沉浸模式设计文档

## 1. 目标
为 Windows 平台提供一个无边框、无标题栏的沉浸式窗口模式。该模式保持游戏原有的 16:9 比例缩放，支持窗口自由拖拽，并保留标准的顶级窗口行为（可被其他窗口覆盖，也可置顶），提供纯净的挂机体验。

## 2. 技术实现

### 2.1 模式进入策略 (Entry Strategy)
游戏提供两种运行模式：
1.  **普通模式**：标准的窗口化模式，带有标题栏、边框和缩放控制。
2.  **无边框沉浸模式**：移除所有窗口装饰，适合桌面美化或挂机。

**默认行为**：程序启动时默认进入“普通模式”，用户可通过系统托盘（System Tray）随时进行无缝切换。
**命令行启动**：支持通过参数 `--wallpaper` 直接以无边框模式启动。

### 2.2 窗口样式实现 (Win32 & window_manager)
为了实现极致的视觉纯净度，系统通过 `win32` 原生 API 与 `window_manager` 插件深度协同。为了兼容多平台开发，所有原生调用均封装在 `WindowController` 抽象层下：

1.  **平台隔离架构 (Abstraction Layer)**：
    - **`WindowController`**：入口文件，使用条件导出根据平台选择实现。
    - **`window_controller_windows.dart`**：包含 FFI 和 Win32 API 调用的 Windows 原生实现。
    - **`window_controller_stub.dart`**：为 Web/Mac 提供空方法，确保跨平台编译通过。

2.  **彻底移除装饰 (WS_POPUP)**：
    - 使用原生 `GetWindowLongPtr` 和 `SetWindowLongPtr` 操作样式位。
    - 显式剥离 `WS_CAPTION` (标题栏)、`WS_THICKFRAME` (厚边框)、`WS_BORDER` (细边框) 等标志位。
    - 禁用 Windows 11 自动圆角 (`DWMWCP_DONOTROUND`)，并将 DWM 边距 (`DwmExtendFrameIntoClientArea`) 设为 0。

3.  **动态比例控制**：
    - **进入沉浸模式**：调用 `setAspectRatio(0)` 临时禁用比例限制。这解决了当屏幕比例非 16:9 时，插件强制限制导致的内部留白问题。
    - **恢复窗口模式**：重新启用 `setAspectRatio(16/9)` 以维持标准布局。

4.  **平滑切换机制 (Anti-Flicker)**：
    - **隐身切换策略**：在切换样式瞬间，通过 `setOpacity(0.0)` 和原生 `ShowWindow(hwnd, SW_HIDE)` 将窗口完全隐藏。
    - **渲染预热**：在窗口不可见状态下完成样式修改，并增加约 100-150ms 延迟，确保 Flutter 引擎完成首帧透明渲染后再重新显示 (`SW_SHOW`) 并恢复不透明度。

5.  **布局重同步技巧 (Layout Re-sync)**：
    - **微调诱导重绘**：从沉浸模式切回窗口模式时，通过设置非整数尺寸（如 `1280.1 x 720.1`）强制诱导 Flutter 渲染管线重新计算可用空间。这解决了因边框重新出现而导致的内容铺不满（或溢出）的问题。

6.  **视觉氛围：边缘羽化 (Feathering)**：
    - 在沉浸模式下，UI 层使用 `ShaderMask` 实现窗口边缘 2% 范围内的 Alpha 平滑过渡，使画面与桌面背景自然融合。

### 2.3 交互逻辑：位置锁定与任务栏
- **位置锁定**：在沉浸模式下，屏蔽 `windowManager.startDragging()`，使窗口无法被鼠标移动，锁定在用户设置的位置。
- **全局拖拽 (仅限普通模式)**：仅在普通模式下，允许通过点击 UI 背景层进行全窗口拖拽。
- **任务栏同步**：进入沉浸模式时执行 `setSkipTaskbar(true)`，恢复时执行 `setSkipTaskbar(false)`。

### 2.4 系统托盘控制 (System Tray)
托盘图标是切换模式的核心交互入口。同 `WindowController` 一样，托盘逻辑也通过 `TrayController` 进行平台抽象：
1.  **跨平台分发**：在非桌面环境（Web）下，托盘初始化和菜单操作被自动忽略。
2.  **动态菜单**：菜单项会根据当前窗口状态实时变化：
    - 普通模式下显示：**“无边框窗口化 (Borderless Mode)”**
    - 沉浸模式下显示：**“恢复窗口化 (Restore Windowed)”**
3.  **快捷切换**：左键单击托盘图标可直接触发模式切换（Toggle）。
4.  **常规功能**：右键菜单提供“退出游戏”功能，安全关闭进程。

## 3. UI 适配原则
- **比例锁定**：始终保持 16:9 的设计比例（1920x1080 设计稿）。
- **缩放容器**：使用 `ScaleWrapper` 确保 UI 内容在窗口大小变化时能自动等比缩放，避免出现布局溢出（Overflow）报错。

## 4. 运行状态
- **沉浸模式**：无边框 (WS_POPUP)、边缘羽化消融 (ShaderMask)、位置锁定、不占任务栏空间。
- **普通模式**：标准窗口、全屏不透明、支持自由拖拽和调整大小。
