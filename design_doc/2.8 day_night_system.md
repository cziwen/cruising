# 2.8 昼夜系统（Day Night System）

## 2.8.1 概述

昼夜系统负责管理游戏内的时间流逝、昼夜循环、季节变化和天体位置计算。系统使用统一的 dt（delta time）增量更新机制，确保所有时间相关系统精确同步。

## 2.8.2 核心要素

### 时间单位
- **游戏分钟**：基础时间单位，一天1440分钟（24小时）
- **游戏小时**：60游戏分钟 = 1游戏小时
- **游戏天**：1440游戏分钟 = 1游戏天
- **现实时间换算**：
  - **航行中**：1现实秒 = 1游戏小时 = 60游戏分钟
  - **在港口**：1现实秒 = 1游戏分钟

### 时间比例
- **航行时间比例 (cruisingTimeScale)**：60.0
  - 1现实秒 = 60游戏分钟 = 1游戏小时
- **港口时间比例 (portTimeScale)**：1.0
  - 1现实秒 = 1游戏分钟
- **时间倍数 (timeMultiplier)**：可调整的倍数（0.1x - 100.0x）
  - 用于调试，加快或减慢游戏时间
  - 默认值：1.0x（正常速度）

### 昼夜周期
- **一天时长**：1440游戏分钟（24游戏小时）
- **白天时段**：6:00 - 18:00（360 - 1080分钟）
- **夜晚时段**：18:00 - 6:00（1080 - 360分钟）
- **默认起始时间**：6:00（日出）

### 季节系统
- **一年天数**：120天
- **季节数量**：4个季节（春、夏、秋、冬）
- **每季节天数**：30天
- **季节顺序**：春 → 夏 → 秋 → 冬 → 循环

## 2.8.3 时间更新机制

### dt 增量更新
系统使用 dt（delta time）增量方式更新，每帧精确计算：

```dart
dtGameMinutes = dtRealSeconds * currentTimeScale * timeMultiplier
```

- `dtRealSeconds`：实际经过的秒数（每帧增量）
- `currentTimeScale`：当前环境的时间比例（航行时为 60.0，港口时为 1.0）
- `timeMultiplier`：时间倍数（0.1 - 100.0）

### 累积时间
- 使用 `_accumulatedGameMinutes` 累积游戏内时间（精确到分钟）
- 每帧更新累积值
- 整数分钟数用于显示和逻辑判断

### 暂停/恢复
- **暂停**：`pause()` - 停止时间流逝
- **恢复**：`resume()` - 恢复时间流逝
- **使用场景**：
  - 手动或特殊事件触发时使用
  - 注：现在到港后时间不再自动暂停，而是切换到较低的流逝比例。

## 2.8.4 时间显示

### 当前时间
- **格式**：HH:mm（显示小时和分钟）
- **计算**：基于累积的游戏内时间
- **更新**：实时更新（通过 AnimatedBuilder）

### 当前日期
- **格式**：季节 + 日期（如"春 15日"）
- **计算**：基于当前天数（1-120）
- **实现**：通过 `getSeasonDateString(l10n)` 获取本地化字符串
- **季节判断**：根据天数计算当前季节

### 时间显示位置
- **UI层**：左上角时间显示组件
- **参考**：详见 `2.5 ui_system.md`

## 2.8.5 昼夜判断

### 白天/夜晚判断
- **白天**：`isDaytime` - 6:00 到 18:00
- **夜晚**：`isNighttime` - 18:00 到 6:00
- **计算**：基于累积时间在一天中的位置

### 3. 昼夜周期进度
- **范围**：0.0 - 1.0
- **基准点**：以 **6:00（360分钟）** 为 0.0 起点。
- **映射关系**：
  - **0.0**：日出（6:00）
  - **0.25**：正午（12:00）
  - **0.5**：日落（18:00）
  - **0.75**：午夜（0:00）
  - **1.0**：下一个日出
- **用途**：用于计算太阳/月亮位置、透明度以及全局视觉滤镜效果。
- **计算公式**：`progress = (currentMinutes - 360 + 1440) % 1440 / 1440`

## 2.8.6 视觉效果系统（Visual Effects）

系统通过动态调整颜色矩阵（Color Matrix）和渐变色，在视觉上表现时间流逝。与传统的全局滤镜不同，本系统采用了**分层视觉滤镜**，为不同游戏元素提供定制化的视觉表现。

### 分层视觉滤镜
- **计算逻辑**：基于 `dayCycleProgress` 和 `VisualLayerType` 为各层独立计算亮度（Brightness）、饱和度（Saturation）和对比度（Contrast）。
- **层级类型 (`VisualLayerType`)**：
  - `ocean`：海底背景和远景波浪，深夜最暗。
  - `island`：港口和岛屿，深夜保持较高清晰度。
  - `ship`：玩家和敌方船只，深夜最亮且色彩最鲜艳。
  - `wave`：前景和近景波浪，夜间对比度适中。
  - `cloud`：云层，提供氛围感。

### 午夜 (0.75) 参数对比
| 层级类型 | 亮度 (Min Brightness) | 饱和度 (Min Saturation) | 对比度 (Min Contrast) |
| :--- | :--- | :--- | :--- |
| **ship (船只)** | 0.9 | 1.0 (原色) | 1.0 |
| **island (岛屿)** | 0.9 | 1.0 (原色) | 1.0 |
| **wave (波浪)** | 0.65 | 0.6 | 0.95 |
| **cloud (云层)** | 0.6 | 0.7 | 0.85 |
| **ocean (海洋)** | 0.55 | 0.5 | 0.8 |

- **应用范围**：海底背景、海浪、云朵、港口岛屿、船只、前景波浪。

### 天空与海面渐变系统
- **动态色彩**：天空和海面颜色随时间平滑插值，且两者在时间轴上完全对齐。
- **阶段划分**（6阶段同步）：
  - **黎明 (0.0 - 0.1)**：6:00 - 8:24，从黄昏色过渡到白天色。
  - **白天 (0.1 - 0.4)**：8:24 - 15:36，保持明亮的白天色彩。
  - **黄昏 (0.4 - 0.5)**：15:36 - 18:00，从白天色过渡到黄昏色。
  - **入夜 (0.5 - 0.6)**：18:00 - 20:24，从黄昏色过渡到深沉的夜晚色。
  - **夜晚 (0.6 - 0.9)**：20:24 - 3:36，保持深邃的夜晚色彩。
  - **黎明前 (0.9 - 1.0)**：3:36 - 6:00，从夜晚色过渡到黎明色，完成循环。
- **视觉分离**：
  - 天空渐变仅应用于屏幕顶部 40% 的区域。
  - 海面渐变作为全屏基底，与海底（underwater）图层配合，表现海水深浅变化。

## 2.8.7 天体系统

### 太阳/月亮位置
- **计算器**：`CelestialBodyPosition`
- **轨迹**：弧形轨迹（从右到左）
- **太阳**：白天显示（0.0 - 0.5 进度）
- **月亮**：夜晚显示（0.5 - 1.0 进度）

### 位置计算
- **X坐标**：从右到左线性移动
- **Y坐标**：弧形轨迹（使用正弦函数）
- **参数**：
  - 弧形高度：屏幕高度的25%
  - 中心Y：屏幕上方15%再调高50像素
  - 起始X：屏幕右侧外
  - 结束X：屏幕左侧外

### 透明度计算
- **太阳**：
  - 日出时淡入（0.0 - 0.1）
  - 正午完全显示（0.1 - 0.4）
  - 日落时淡出（0.4 - 0.5）
  - 夜晚完全隐藏（0.5 - 1.0）
- **月亮**：
  - 月出时淡入（0.5 - 0.6）
  - 午夜完全显示（0.6 - 0.9）
  - 月落时淡出（0.9 - 1.0）
  - 白天完全隐藏（0.0 - 0.5）

### 天体层位置
- **渲染层**：Layer 0.5（天体层）
- **参考**：详见 `2.6 scene_system.md`

## 2.8.7 日期系统

### 日期跟踪
- **当前日期**：1 - 120（一年）
- **跨年处理**：超过120天后重置为1
- **日期增加**：每天00:00时自动增加

### 季节计算
- **春季**：第1-30天
- **夏季**：第31-60天
- **秋季**：第61-90天
- **冬季**：第91-120天

### 季节日期
- **格式**：季节名称 + 日期（如"春 15日"）
- **计算**：当前日期在季节中的位置（1-30）

## 2.8.8 时间事件

### 午夜跨越检测
- **触发时机**：从23:00跨越到00:00
- **用途**：
  - 触发工资结算
  - 触发酒馆船员刷新
  - 增加日期
  - 检查价格更新（每7天）

### 工资结算
- **触发**：每天00:00
- **处理**：在 `GameState` 中处理
- **参考**：详见 `2.4 crew_system.md`

### 价格更新
- **触发**：每7天
- **处理**：在 `GameState` 中处理
- **参考**：详见 `2.1 trade_system.md`

## 2.8.9 技术实现

### 核心类
- **DayNightSystem**：昼夜系统管理器。
- **CelestialBodyPosition**：天体位置计算器。
- **DayNightVisualUtils**：视觉效果工具类，提供颜色滤镜和天空渐变计算。

### 主要方法

## 2.8.10 与游戏系统的关系

### 场景系统
- 提供昼夜周期进度，用于计算天体位置
- 天体层（Layer 0.5）显示太阳/月亮
- **参考**：`2.6 scene_system.md`

### UI系统
- 提供当前时间，用于时间显示组件
- 时间显示位于左上角（Layer 3.5）
- **参考**：`2.5 ui_system.md`

### 导航系统
- 时间流逝影响航行进度（如果基于游戏时间）
- 航行时时间继续流逝
- **参考**：`2.2 navigation_system.md`

### 船员系统
- 每天00:00触发工资结算
- 每天00:00刷新港口酒馆的可招募船员
- 时间倍数影响结算和刷新频率
- **参考**：`2.4 crew_system.md`

### 贸易系统
- 每7天触发价格更新
- 时间倍数影响价格更新频率
- **参考**：`2.1 trade_system.md`

### 调试系统
- 提供时间倍数调整功能
- 时间倍数直接影响昼夜系统更新速度
- **参考**：`2.7 debug_system.md`
