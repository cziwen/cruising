# 3.0 Tutorial Narrative Design

## 3.0.1 设计目标
本教程旨在通过一个简单的剧情引导玩家理解游戏的核心循环（贸易-升级-建设），同时为玩家提供一个明确的早期目标：**复兴家乡岛屿**。

## 3.0.2 剧情背景
玩家扮演一名年轻的船长，继承了祖父留下的一艘破旧小船。回到曾经繁荣但现在衰落的**主岛（Home Island）**，在老船员“巴纳比（Barnaby）”的指引下，开启重振家乡的贸易之旅。

## 3.0.3 核心流程与节奏

### 第一阶段：起航 (The Departure)
- **剧情**: 祖父的遗产。
- **目标**: 离开主岛前往第一个贸易港口。
- **教学点**: 导航系统、港口列表。

### 第二阶段：初识贸易 (First Trade)
- **剧情**: 发现商机。
- **目标**: 在港口买入低价货物。
- **教学点**: 贸易界面、动态价格（买入）、载货量限制。

### 第三阶段：赚取首金 (First Profit)
- **剧情**: 跨海投机。
- **目标**: 航行至另一个港口高价卖出货物。
- **教学点**: 动态价格（卖出）、利润概念。

### 第四阶段：工欲善其事 (Ship Upgrade)
- **剧情**: 工欲善其事，必先利其器。
- **目标**: 升级船只载货量。
- **教学点**: 船厂系统。

### 第五阶段：复兴家园 (Homecoming & Growth)
- **剧情**: 归乡与建设。
- **目标**: 返回主岛，升级税收等级，领取第一笔税收。
- **教学点**: 主岛系统（大厅、升级、税收）、游戏核心循环闭环。

## 3.0.5 引导优化细节
1.  **分段式引导**: 任务不再一口气塞给玩家，而是在关键节点（如到达港口、关闭面板）触发下一步。
2.  **强制性与屏蔽**: 对于关键步骤（如点击市场、点击升级），开启 `isMandatory: true`，屏蔽无关点击。
3.  **视觉聚焦**: 只有在需要玩家操作具体组件时才高亮，其他叙事环节使用全屏遮罩或透明遮罩。
4.  **叙事平衡**: 文本控制在 2-3 句话内，既有代入感又不影响操作效率。
