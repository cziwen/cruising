# 2.14 音频系统 (Audio System)

## 概述
音频系统负责游戏背景音乐 (BGM) 和音效 (SFX) 的播放与管理。该系统支持基于游戏状态的配置驱动播放、音轨随机选择、平滑的交叉淡入淡出 (Cross-fading) 以及多音轨环境音效的重叠播放。

## 核心组件

### 1. 配置文件

#### 背景音乐配置 (`assets/config/music.json`)
定义不同游戏状态对应的音乐池。
```json
{
  "main_menu": ["music/main_menu/track1.mp3"],
  "cruising": ["music/cruising/track1.mp3"],
  "combat": ["music/combat/track1.mp3"]
}
```

#### 音效配置 (`assets/config/sfx.json`)
定义环境音效 (Ambient) 和单次音效 (One-shot)。
- **环境音 (Ambient)**: 在特定状态下间歇性、随机播放的背景音（如海浪、海鸥）。
- **单次音效 (One-shot)**: 由 UI 交互或特定游戏事件触发的即时音效。

### 2. 音频管理器 (`lib/systems/music_system.dart`)
单例类 `MusicSystem` 管理所有音频播放。

- **BGM 管理 (Music)**: 
  - 使用两个 `AudioPlayer` 实例实现交叉淡入淡出。
  - 切换状态时自动选择新音轨并平滑过渡。
- **SFX 管理 (Sound Effects)**:
  - **单次播放**: 使用播放器池支持多个音效重叠。
  - **环境音控制器**: 管理间歇性播放逻辑，支持随机音轨和随机间隔。
- **音量控制**: 独立管理背景音乐和音效的音量。支持零音量下的即时停止与播放拦截。

## 游戏集成

通过状态字符串触发音频环境切换：

| 状态名 | 触发时机 | 默认 BGM | 默认环境音 (Ambient) |
| :--- | :--- | :--- | :--- |
| `main_menu` | 主菜单 | `main_menu` 池 | - |
| `cruising` | 海上航行 | `cruising` 池 | `wave`, `seagull` (随机) |
| `port` | 停靠港口 | - | `wave`, `seagull` (频繁) |
| `combat` | 战斗 | `combat` 池 | - |
| `victory` | 战斗胜利 | - | 欢呼声 (One-shot) |

## 技术实现细节

### 多音轨叠加
系统维护多个 `AudioPlayer` 实例：
1. `BGM_A` / `BGM_B`: 用于音乐交叉淡出。
2. `SFX_Pool`: 用于并发播放多个短促音效。
3. `Ambient_Players`: 每个环境音类型（如海浪、海鸥）分配独立的播放逻辑，避免互相阻塞。

### 环境音随机逻辑
每个环境音控制器在播放完当前音轨后，会随机等待一段延迟（例如 5-15 秒），然后再次触发该分类下的随机音轨播放。

### 音量与静音管理
为了确保音量设置为 0 时完全静音且不消耗多余资源：
1. **即时停止**: 当音量设置为 0 时，系统会立即停止所有当前正在播放的对应类型（BGM 或 SFX）的播放器。
2. **播放拦截**: 所有的播放请求（包括单次音效和环境音）在执行前都会检查当前音量。若音量为 0，则跳过实际的播放调用。
3. **动态淡入淡出**: 在音乐交叉淡入淡出过程中，音量的计算会实时参考最新的全局音量设置，确保在切换过程中调整音量也能即时生效。
