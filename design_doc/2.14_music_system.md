# 2.14 音乐系统 (Music System)

## 概述
音乐系统负责游戏背景音乐 (BGM) 的播放与管理。该系统支持基于游戏状态的配置驱动播放、音轨随机选择以及平滑的交叉淡入淡出 (Cross-fading) 效果。

## 核心组件

### 1. 配置文件 (`assets/config/music.json`)
音乐系统通过 JSON 配置文件定义不同游戏状态对应的音乐池。目前仅支持三种核心状态。

**结构示例：**
```json
{
  "main_menu": [
    "music/main_menu/track1.mp3",
    "music/main_menu/track2.mp3"
  ],
  "cruising": [
    "music/cruising/track1.mp3",
    "music/cruising/track2.mp3"
  ],
  "combat": [
    "music/combat/track1.mp3",
    "music/combat/track2.mp3"
  ]
}
```

### 2. 音乐管理器 (`lib/systems/music_system.dart`)
单例类 `MusicSystem` 是系统的核心，管理播放器实例和音量。

- **交叉淡入淡出**：使用两个 `AudioPlayer` 实例。当切换音乐时，当前播放器音量逐渐减小直至停止，而新播放器音量从 0 逐渐增加。
- **状态播放**：通过 `playState(String stateName)` 方法触发。
  - **匹配成功**：从该状态对应的列表中随机选一首播放。
  - **匹配失败**：如果没有在配置中找到对应的状态名，系统将平滑淡出并停止当前正在播放的所有背景音乐。
- **音量控制**：支持全局背景音乐音量设置。

## 游戏集成

代码中通过以下状态字符串触发音乐切换。如果配置中未定义的字符串（如 `port`, `victory`, `defeat`），将导致背景音乐停止：

| 状态名 | 触发时机 |
| :--- | :--- |
| `main_menu` | 进入主菜单界面时 |
| `cruising` | 玩家船只在海上航行时 |
| `combat` | 进入战斗场景时 |

## 技术实现细节

### 淡入淡出算法
淡入淡出通过 `Timer.periodic` 实现，在 1.5 秒内分 20 步完成：
1. **当前播放器**：`volume = (1 - progress) * globalVolume`
2. **目标播放器**：`volume = progress * globalVolume`

其中 `progress` 从 0 增加到 1。

## 扩展建议
- **状态映射**：如果希望在港口播放主菜单音乐，只需在 `music.json` 中添加 `"port": [...]` 并指向对应的资源即可。
- **环境音层**：未来可以增加独立的环境音层（如海浪、海鸟声）以增强沉浸感。
