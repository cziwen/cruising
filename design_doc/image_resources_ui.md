# UI 元素图片资源

## 概述

当前的 UI 系统主要基于 Flutter 的标准组件库（Material Design）构建，结合自定义样式实现简约的视觉风格，而非完全依赖外部图片资产。

---

## 核心 UI 构成

### 1. 纸质风格对话框与面板 (Paper UI)
- **实现**: 使用自定义的 `PaperDialog` 组件封装。
- **背景**: 使用高质量的纸张素材图片（`assets/paper_ui/Sprites/Book Desk/`）。
- **样式**: 深褐色文字 (`#4E342E`)，配合纸张纹理，营造复古航海日志感。

#### 资产分配表
| 资产文件名 | 尺寸类型 | 应用场景 |
| :--- | :--- | :--- |
| `4.png` | 小型面板 | 设置界面、港口选择、简易提示 |
| `5.png` | 中型面板 | 船员管理、小型功能面板 |
| `6.png` | 大型面板 | 酒馆、大厅主界面 |
| `7.png` | 宽屏大型面板 | 市场交易、船厂升级、复杂报表 |

### 2. 自定义纸质按钮 (PaperButton)
- **实现**: 使用自定义的 `PaperButton` 组件，替代了标准 Material 按钮。
- **资产来源**: `assets/paper_ui/Sprites/Content/4_Buttons/` 下的精灵图。
- **状态支持**: 每个按钮由一对图片（普通/按下）组成，通过点击交互实时切换。
- **样式分类**:
  - **棕色 (0-1.png)**: 默认操作、返回、取消。
  - **绿色 (2-3.png)**: 确认交易、出发、保存。
  - **蓝色 (4-5.png)**: 设置中次要操作、存档覆盖。
  - **红色 (6-7.png)**: 解雇、删除存档。
  - **金色 (8-9.png)**: 特殊升级、加成提示。

### 3. 图标与状态栏
- **图标**: 结合 Flutter 材质图标库 (`Icons`) 和 Emoji。
