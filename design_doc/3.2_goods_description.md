# 3.2 货物描述文档 (Goods Description)

## 3.2.1 概述
本手册详细描述了《Cruising》中所有可交易货物的属性、背景及经济定位。货物分为四个主要类别：货币、基础物资、工业材料和奢侈品。

---

## 3.2.2 货物详细清单

### 1. 货币 (Currency)
| ID | 名称 | 重量 | 描述 |
| :--- | :--- | :--- | :--- |
| `gold` | 金币 | 0.0 kg | 全球通用的贸易媒介，不占用船只载货空间。 |

---

### 2. 基础物资 (Basic Goods)
主要用于维持岛屿基本运作及船员补给，需求量大且价格波动相对平缓。所有港口均需提供此类物资。

| ID | 名称 | 重量 | 基础价格 (P₀) | 贸易建议 |
| :--- | :--- | :--- | :--- | :--- |
| `food` | 食物 | 1.0 kg | 12.0 | 最基本的补给品，在几乎所有港口都有稳定的供需。 |
| `water` | 淡水 | 1.0 kg | 8.0 | 航行必需品，在降水丰富的岛屿价格极低。 |
| `rum` | 朗姆酒 | 1.2 kg | 20.0 | 水手的心头好，能够提升士气，在热带港口产量较高。 |

---

### 3. 工业材料 (Materials)
用于建设、修船及港口升级的物资，重量较大，对船只载重有较高要求。仅在产地或需求港口交易。

| ID | 名称 | 重量 | 基础价格 (P₀) | 贸易建议 |
| :--- | :--- | :--- | :--- | :--- |
| `wood` | 木材 | 2.0 kg | 16.0 | 基础建筑材料，林木茂盛的岛屿是主要产地。 |
| `metal` | 金属 | 5.0 kg | 25.0 | 极其沉重，但作为高级工具和武器原材料，利润空间大。 |
| `stone` | 石材 | 4.0 kg | 18.0 | 港口设施升级的必备材料，在矿产岛屿大量产出。 |
| `cloth` | 布料 | 1.5 kg | 15.0 | 用于制作风帆，在棉花产地或纺织中心价格更优。 |
| `leather` | 皮革 | 1.8 kg | 22.0 | 坚韧耐用的材料，由畜牧业发达的港口供应。 |

---

### 4. 奢侈品 (Luxury Goods)
高单价、低重量、高敏感度的货物，是中后期获取暴利的主要来源。

| ID | 名称 | 重量 | 基础价格 (P₀) | 贸易建议 |
| :--- | :--- | :--- | :--- | :--- |
| `spice` | 香料 | 0.5 kg | 30.0 | 来自遥远东方的异域物资，长途贸易的利润基石。 |
| `silk` | 丝绸 | 0.3 kg | 45.0 | 极轻且昂贵，只有大型繁荣港口才有稳定库存。 |
| `ivory` | 象牙 | 2.5 kg | 60.0 | 稀有珍贵的材料，受限于产地，属于高度匮乏物资。 |
| `artwork` | 艺术品 | 3.0 kg | 80.0 | 最高价值的单品，价格受市场情绪波动极大。 |

---

## 3.2.3 类别经济分析

### 价格敏感度 (α)
- **基础物资 (α: 0.10 - 0.18)**：对库存变化不敏感，即使大规模买卖，单价变化也较小。
- **工业材料 (α: 0.12 - 0.20)**：敏感度适中，适合作为大宗贸易的稳定支柱。
- **奢侈品 (α: 0.25 - 0.35)**：高度敏感，少量倾销或抢购会导致价格剧烈波动，操作不当可能导致亏损。

### 载重效率 (Profit per kg)
- **奢侈品**拥有最高的载重利润率（如丝绸），适合小型快速帆船进行长途跑商。
- **工业材料**虽然利润绝对值不低，但沉重的负担要求玩家拥有大型货船（如盖伦船）才能实现规模效益。
